## What I spend time on

* **Design systems** — component libraries with WCAG in mind, Storybook, tokens, and form-associated web controls.
* **Product frontend** — TypeScript / React / Next.js surfaces that sit on those primitives.
* **Tests as a habit** — Vitest, Testing Library, Playwright where the surface needs it.
